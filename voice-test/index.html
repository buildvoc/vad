Two-way voice with Ask the wiki — isolated test

The interface below is an iframe. It uses Whisper on G3 for speech recognition and sends transcripts to the existing Ask the wiki chat via a browser-only local bridge. The Chrome extension returns the completed Ask the wiki answer here for spoken playback, then listening resumes.

Use a trusted microphone context (HTTPS, localhost tunnel, or an explicit Chrome test-only secure-origin exception). The browser bridge requires the two tabs to use ports 8766 and 8180 on G3.
